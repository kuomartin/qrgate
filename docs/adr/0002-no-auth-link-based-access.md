# 掃描端不做帳號系統，以部署連結本身作為存取控制

延續 reg_dev 的 GitHub Pages（通用掃描頁）+ 各活動獨立 Apps Script Web App 部署架構：Web App 部署設定為 `ANYONE_ANONYMOUS`，掃描頁靠網址參數（deployment id）連到對應活動的後台，沒有登入/帳號系統。工作人員專屬連結由主辦方在該活動 Sheet 的自訂選單一鍵產生（含可供手機掃碼開啟的 QR），自行分發給入口人員。

這代表存取控制完全等同於「知道這個連結」，沒有身分驗證層。考量活動是短期、低風險場景，且新增帳號系統會大幅增加複雜度，選擇沿用這個模式而非另建登入機制。若日後有更高安全需求（例如需要追蹤是哪個工作人員執行的入場動作），需要重新評估這個決定。
